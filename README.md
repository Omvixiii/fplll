# fplll

fplll is a library and command-line toolkit for lattice reduction. It provides
floating-point LLL, BKZ (including BKZ 2.0), Slide reduction, self-dual BKZ,
shortest-vector enumeration, and closest-vector enumeration. See the
[usage guide](doc/usage.md) for algorithm options and references.

## Build from source

Install Meson 1.8 or newer, Ninja, a C++23-capable compiler, GMP 4.2 or newer,
MPFR 2.3 or newer, and pkg-config. Choose the final installation prefix when
configuring, then build, test, and install:

```sh
meson setup build --buildtype=release --prefix "$HOME/.local"
meson compile -C build
meson test -C build --print-errorlogs
meson install -C build
```

The default `meson setup build` builds shared and static libraries with the
tests enabled. Meson is available with `uv tool install meson` or
`pipx install meson`; QD is optional (`-Dqd=enabled`).

The [build guide](doc/building.md) covers options, build and install layouts,
sanitizers, coverage, source archives, and downstream use through pkg-config or
Meson's `dependency('fplll')`.

## Command-line tools

The build provides `fplll` for lattice reduction and `latticegen` for generating
example lattices. Matrix rows are basis vectors. For example:

```sh
build/tools/latticegen r 10 1000 | build/tools/fplll -a lll
```
